The Problem

Why courses break

The legacy course toolkit doesn't fit individual, async, certification-track learners.

📄
Word + PowerPoint
Static. Versionless. Painful to fork. Lose every speaker note when shared.
👥
Group-only exercises
Don't work for self-paced or async cohorts. Block the certification path.
🪞
Inconsistent visual identity
Each module looks different. Brand erodes module-to-module.
🛠
No interactive artifacts
Learners watch. They don't ship. Submission is a deck, not a repo.
🚪
Locked formats
PowerPoint files trapped behind office licenses. Can't ship to GitHub Pages.
🔁
Drift on every refresh
Hand-edit a deck → six other places break. No source of truth.

Voice Rules

100% individual. No groups. No live demo.

Click each claim to reveal the verdict.
FALSE
"Group exercises build collaboration skills."
They build scheduling skills. Async-first individual exercises with self-review + AI-review beat group breakouts on every learning metric we measured.
FALSE
"Live demos prove understanding."
Live demos prove rehearsal. A repo with versioned artifacts proves understanding. Submission = repo URL within 7 days. No live demo required.
TRUE
"Speaker notes leak into the wrong deck."
Without a strict instructor / shareable split, and a generator that enforces it, every iteration leaks notes into the deck students screenshot. Two file names. One source of truth.
BannedReplace with
"your group" / "as a team""you" / "on your own"
"breakout""lab" or "applied work"
"pair up" / "with a partner"(delete)
"peer red-team""AI-review (paste artifact + verbatim prompt into ChatGPT/Claude)"
"report back to the room""post in the cohort channel"

Get Started

Three ways to use this skill

A · Paste anywhere
Clone the repo. Copy PROMPT.md contents into ChatGPT, Claude.ai, or any chat tool's system prompt field. Tell the model to fetch reference assets from GitHub on demand.
B · Symlink as agent skill
Symlink the folder into ~/.cursor/skills/ and/or ~/.claude/skills/. Trigger phrases activate the skill automatically.
C · Use manually
No agent at all. Read PROMPT.md. Copy the design system into your decks. Author by hand using component-templates.md as reference.

Key Takeaways

course-to-github-pages, in five lines

Tool-agnostic = portable content + thin wrappers. PROMPT.md works anywhere. CLAUDE.md works in Claude Code/Project. SKILL.md works in Cursor/Claude Code skills. One content tree.

Generators are the source of truth. Never hand-edit a generated deck. Update the generator and re-run. Idempotent.

Voice is 100% individual. Solo. Async. Self-review + AI-review. Submission = repo URL within 7 days. No live demo.

The design system is locked. Navy #07162C · Poppins/Lato/IBM Plex Mono. Every deck. Same UI furniture.

The repo IS the certificate. Not a deck. Not a doc. A versioned, forkable GitHub repo with one folder per module.
